- React 18
- Vite
- Tailwind CSS
- React Router DOM
- React Helmet Async
- Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This site is configured for static deployment. To deploy on GitHub Pages or any static host:

1. Update `vite.config.js` base URL if needed
2. Run `npm run build`
3. Deploy the `dist/` folder

## Google Workspace for Nonprofits Compliance

This website is designed to meet Google's verification requirements:

- Domain matches organization name (mag-farm-corp.bond)
- No placeholder or "Lorem Ipsum" content
- EIN (92-0336379) visible on multiple pages
- Physical address displayed throughout site
- Mission statement clearly stated
- Functional navigation and professional design
- Schema.org Organization JSON-LD with NGO type and taxID
